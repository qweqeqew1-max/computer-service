
# PCMaster — сайт компьютерного мастера

Учебный проект адаптивного сайта для сервиса ремонта компьютеров
и ноутбуков. Создан с использованием HTML, CSS и JavaScript.

## Возможности

- Адаптивная вёрстка для компьютеров, планшетов и телефонов.
- Мобильное навигационное меню.
- Карточки услуг с примерными ценами.
- Блок преимуществ и демонстрационные отзывы.
- Форма заявки с проверкой обязательных полей.
- Выбор услуги с автоматическим переходом к форме.
- Подготовка письма через mailto.
- Автоматическое отображение текущего года.

## Технологии

- HTML5
- CSS3
- JavaScript (без сторонних библиотек)

## Как запустить

1. Скачайте или склонируйте репозиторий.
2. Откройте файл index.html в браузере.
3. Перейдите в разделы сайта и проверьте кнопки и форму.

Для редактирования рекомендуется Visual Studio Code.

## Перед публикацией

- Замените демонстрационные телефон и электронную почту.
- Укажите реальные цены и условия услуг.
- Замените вымышленные отзывы настоящими, если они появятся.
- Проверьте работу формы на устройстве с настроенной почтой.

## Ограничения

Проект не использует сервер или базу данных.
Заявки автоматически не сохраняются и не отправляются:
форма формирует черновик письма в почтовом приложении.

Цены, отзывы, бренд и контакты приведены в демонстрационных целях.
